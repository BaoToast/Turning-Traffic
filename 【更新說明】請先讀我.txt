路口轉向分析 — GitHub Pages 更新包 v2.1.22
=================================================

本版修的是使用者回報的兩項，外加一個會讓資料整個不見的嚴重問題。
-----------------------------------------------------------------

■ 全新的瀏覽器從頭到尾不會存檔（本輪查出，影響最大）

  程式在載入時如果發現這台電腦還沒有資料，會直接跳出而沒有把
  「可以開始存檔」的開關打開，於是後面每一次存檔都被擋住。
  症狀是：建立計畫、匯入一整季、核對、鎖定，畫面上一切正常，
  只要重新整理或關掉分頁就全部消失，而且沒有任何訊息。
  在另一台空白電腦還原備份也一樣，還原完看起來成功、重開就沒了。
  已改為「沒有資料可讀」時一樣要解鎖存檔。
  （實測：全新瀏覽器建立計畫後 localStorage 完全沒有寫入。）

■ 現在可以只備份一個計畫

  舊版「完整 ZIP」與「JSON 純資料」其實是同一份東西——整台電腦的所有計畫，
  只差在壓不壓縮，畫面上卻沒有寫。使用者在 A 電腦匯出 A 計畫帶到 B 電腦，
  結果 B 電腦冒出 A 電腦裡的每一個計畫，而 B 電腦原有的計畫被整批覆蓋。
  現在分成「只備份目前這個計畫」與「備份全部計畫」兩組，檔名帶計畫編號與名稱；
  單一計畫的備份匯入時是「併入」（同一個計畫被取代，其他計畫不動），
  全部計畫的備份匯入時才是「完整取代」，動手前都會寫清楚讓您確認。
  成果審核狀態、鎖定狀態與還原點都會跟著備份走。

■「成果審核狀態」現在真的管得到鎖定

  舊版不論選哪一個狀態都鎖得起來，那個欄位等於只是備註。現在：
  「需修正」會擋下鎖定並列出是哪幾個路口；「待核對」鎖定前會再問一次；
  鎖定之後審核狀態就改不動（要改先解除鎖定）。
  核對工作台另外新增一張「本筆成果鎖定狀態」卡，寫出何時鎖的、
  鎖定當時的版本、鎖定後內容有沒有被動過。

■ 下載的檔名不再變成 download

  產生下載用的連結沒有掛進頁面，部分瀏覽器會忽略指定的檔名。

■ Excel 解析套件的安全警示

  xlsx 套件有一則上游警示，npm 上目前沒有修好的版本可以升。
  本版在自己的邊界處理：解析時關掉用不到的公式、內嵌 HTML 與巨集，
  並在解析前後比對瀏覽器的內建物件——一旦真的被動到就中止這次匯入
  並指出是哪一個檔案。


如何更新
-----------------------------------------------------------------
把本壓縮檔內的所有檔案，覆蓋到 GitHub repository
（https://github.com/baotoast/Turning-Traffic）的根目錄，然後 commit + push。
GitHub Pages 會自動重新發布，約 1～3 分鐘。

部署完成後請確認：左側欄下方顯示「v2.1.22」，
「新手操作手冊」頁的兩個下載連結點得下去（不是 404）。
